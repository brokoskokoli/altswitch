Datenschutz

Gilt für alle Versionen von AltSwitch. Stand: 18. Oktober 2026.

Kurz gesagt: AltSwitch sammelt, speichert und teilt keine personenbezogenen Daten und verbindet sich nie mit dem Internet. Alles, was die App von deinen Fenstern sieht, bleibt auf deinem Mac.

Keine Datenerhebung

AltSwitch hat keine Analyse, keine Telemetrie, keinen Absturzbericht-Dienst, keine Werbung und keine Benutzerkonten. Die Entwickler erhalten keine Informationen über dich oder deine Nutzung der App.

Keine Netzverbindungen

AltSwitch baut überhaupt keine Netzverbindungen auf – nicht einmal für eine Update-Prüfung. Updates kommen über GitHub Releases oder Homebrew, wenn du sie installierst.

Was auf deinem Computer bleibt

  • Fensterliste und Vorschauen. Für die Karten liest AltSwitch Titel und Position deiner offenen Fenster und erstellt mit der Berechtigung „Bildschirmaufnahme“ kleine Vorschaubilder. Diese liegen nur im Arbeitsspeicher, solange die App läuft, werden nie auf die Festplatte geschrieben und verlassen deinen Mac nie.
  • Einstellungen. Deine Auswahl (Kurzbefehl, Ansicht, Einrichtung abgeschlossen) steht in ~/Library/Preferences/com.stefanrichter.altswitch.plist.
  • Start beim Anmelden wird bei macOS eingetragen (Systemeinstellungen → Allgemein → Anmeldeobjekte) und lässt sich dort oder im AltSwitch-Menü abschalten.

Berechtigungen

  • Bedienungshilfen – um den Kurzbefehl abzufangen und das gewählte Fenster nach vorn zu holen.
  • Bildschirmaufnahme (optional) – nur für die Vorschaubilder. Ohne sie zeigt AltSwitch App-Symbole.

Beides kannst du jederzeit in Systemeinstellungen → Datenschutz & Sicherheit widerrufen.

Diese Website

Diese Website liegt auf GitHub Pages. Sie setzt keine Cookies, nutzt keine Analyse und lädt nichts von Dritten. GitHub kann beim Aufruf technische Daten wie deine IP-Adresse protokollieren; siehe das GitHub Privacy Statement.
