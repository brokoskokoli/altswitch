# Security Policy

AltSwitch runs with the Accessibility and (optionally) Screen Recording permissions and makes no
network connections. We take bugs that could compromise your computer
seriously.

## Supported versions

Only the latest release receives security fixes. Updates are available on the
[Releases](https://github.com/brokoskokoli/altswitch/releases) page and through Homebrew.

| Version | Supported |
|---|---|
| 1.0.x (latest) | ✅ |
| older | ❌ |

## Reporting a vulnerability

**Please do not open a public issue, discussion or pull request for security problems.**

Report privately via GitHub: open the repository's **Security** tab and click
**[Report a vulnerability](https://github.com/brokoskokoli/altswitch/security/advisories/new)**. Only the
maintainers can see the report.

Please include:

- the AltSwitch version and your operating system version;
- a description of the issue and its impact;
- a minimal proof of concept or steps to reproduce (attach files to the advisory, never post them publicly);
- any crash log.

What to expect:

- acknowledgement within **7 days**;
- an assessment and, for confirmed issues, a fix plan within **30 days**;
- coordinated disclosure: we publish a GitHub security advisory together with the fixed release and
  credit you unless you prefer to stay anonymous.

This is a volunteer project; there is no bug bounty.
